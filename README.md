# Library System

## Description
Simple Library Information System

## Requirements
- PHP
- Composer
- MySQL
- Laravel

## Installation
1. Clone repository ini: `git clone https://github.com/sayyzhil/library-system.git`
2. Masuk ke direktori: `cd library-system`
3. Install dependencies: `composer install`
4. Copy file environment: `cp .env.example .env`
5. Generate application key: `php artisan key:generate`
6. Sesuaikan koneksi database pada file `.env`
7. Jalankan migrasi: `php artisan migrate`
8. Jalankan server: `php artisan serve`
